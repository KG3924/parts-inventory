Items Needing Attention

About these numbers

Cost Value = Σ (Qty × Buy Price) — typical accounting inventory asset value (what you paid).

Sell / Retail Value = Σ (Qty × Sell Price) — potential revenue at list price.

Potential Margin = Sell Value − Cost Value.

Database setup (category column)

Run this once in Supabase → SQL Editor if category filters/import are not working:

alter table inventory add column if not exists category text;
create index if not exists inventory_category_idx on inventory (category);
create index if not exists inventory_source_idx on inventory (source);
